# SimpleCityBuilder
**Software required to download and run the game**
- GitHub Desktop (Recommended)
- Unity (Required)
- Visual Code (Or other code editor)

**Installation** (Using GitHub Desktop)
1. Click the green **Code** button and select **Open with GitHub Desktop**
2. Choose a folder file path where to store the project (e.g. D:/UnityProjects)
3. Click **Clone**
4. Open **Unity Hub**
5. Go to **Projects**
6. Click **Add** button (Next to the blue **New Project** button) and select **Add project from disk**
7. Navigate to the project folder (e.g. D:/UnityProjects), select the top-level folder (SimpleCityBuilder), and click **Add Project**
